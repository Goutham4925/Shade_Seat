# Shade Safe Seat Advisor

## Overview
Shade Safe Seat Advisor is a mobile-first progressive web application that helps commuters choose which side of a vehicle to sit on to avoid direct sunlight during their journey.

## Core Functionality

### Seat Recommendation System
The app provides real-time seat recommendations (left or right side) based on:
- Current GPS location (latitude/longitude)
- Device compass heading (bearing direction)
- Current time of day
- Sun position calculations using the SunCalc library

### How It Works
1. User requests their safe seat recommendation
2. App obtains GPS coordinates via Geolocation API
3. App detects vehicle heading using device compass (DeviceOrientationEvent)
4. Calculates sun azimuth using SunCalc library
5. Compares sun position with vehicle heading
6. Recommends the side of the vehicle that avoids direct sunlight

### Mathematical Logic
```
angle_difference = ((sun_azimuth - vehicle_heading + 540) % 360) - 180

If angle_difference > 0: Sun is on the left → Recommend RIGHT seat
If angle_difference < 0: Sun is on the right → Recommend LEFT seat
```

## Key Features

### 1. Quick Check Mode
- One-tap seat recommendation
- Uses real-time GPS and compass
- Instant visual feedback with vehicle diagram
- Shows sun direction, vehicle heading, and coordinates

### 2. Route Mode
- Enter origin and destination addresses
- Location autocomplete using OpenStreetMap Nominatim API
- Calculates bearing between two points
- Provides seat recommendation for the entire route

### 3. Manual Heading Selection
- Fallback for devices without compass support
- User selects cardinal direction (North, East, South, West)
- Converts to bearing degrees (0°, 90°, 180°, 270°)

### 4. PWA Features
- Installable as standalone app
- Works offline with cached assets
- Native app-like experience
- Service worker for performance

- SunCalc: Sun position calculations

### Browser APIs Used

## Data & Privacy
- No user data is stored or transmitted
- No database required
- All calculations performed client-side
- GPS and compass permissions requested only when needed
- External API calls: Only for geocoding (Nominatim)

## Installation
Available as a Progressive Web App (PWA):
- Visit the web app in any modern browser
- Install to home screen on mobile devices
- Works offline after initial load
- Automatic updates when online

## Browser Compatibility
- Modern browsers with Geolocation API support
- Compass requires DeviceOrientation API (primarily mobile)
- Desktop users can use manual heading selection
- Graceful fallbacks for unsupported features
